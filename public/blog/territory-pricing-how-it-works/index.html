Territory Pricing — The 250 Scale

The canonical IAM pricing model used across weddings.io, videographers.io, roofers.io, industryarmymarketing.com and carpenters.ltd. Slots scale with population. Price scales by million. Always 3 minimum, never more than 10, capped at $50/slot.

Version 1.0 · June 23, 2026 · Weddings.io Editorial

The Rule

Every city starts at 3 slots minimum. Slots scale up with population. The cap is always 10. Price per slot is flat within each population band. Price doubles at 1 million, then steps up $10 per additional million, and caps at $50/slot for cities of 4M+.

Slot Scale — Plain English

  • Under 250K → 3 slots
  • 250K–499K → 4 slots
  • 500K → 6 slots
  • 600K → 7 slots
  • 700K → 9 slots (jumps from 7 to 9, not 8)
  • 800K → 9 slots
  • 1M+ → 10 slots (hard cap, never exceeds 10)

Price Scale — Plain English

  • Under 1M population → $10/slot/month
  • 1M–1.99M → $20/slot/month
  • 2M–2.99M → $30/slot/month
  • 3M–3.99M → $40/slot/month
  • 4M+ → $50/slot/month (cap)

🔒 Sold out = active_slots >= max_slots for the city. Never hardcoded to 3. Derived from population. The vendor who locks first keeps the slot at today's rate as long as they stay active.

The TypeScript Function — Source of Truth

// IAM TERRITORY PRICING — THE 250 SCALE
export function calculateSlotCount(population: number): number {
  if (population < 250000) return 3;
  if (population < 300000) return 4;
  if (population < 500000) return 4;
  if (population < 600000) return 6;
  if (population < 700000) return 7;
  if (population < 1000000) return 9;
  return 10; // Hard cap at 10.
}

export function calculateSlotPrice(population: number): number {
  if (population < 1000000) return 10;
  if (population < 2000000) return 20;
  if (population < 3000000) return 30;
  if (population < 4000000) return 40;
  return 50; // Caps at $50/slot for 4M+ cities
}
