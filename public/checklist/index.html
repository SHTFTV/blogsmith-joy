📅 12+ Months Before

Set wedding budget with both families
Choose wedding dates (check muhurat/auspicious dates)
Create initial guest list
Research and book wedding planner
Book ceremony venue (Gurdwara/Temple/Banquet Hall)
Book reception venue

📅 9-12 Months Before

Book caterer for all events
Book photographer and videographer
Book decorator/mandap vendor
Book DJ/entertainment
Book dhol players for baraat
Start shopping for bridal lehenga
Book pandit/granthi/imam

📅 6-9 Months Before

Send save-the-dates
Book mehendi artist
Book sangeet choreographer
Shop for groom's sherwani
Book bridal makeup artist
Finalize guest list
Order wedding invitations

📅 3-6 Months Before

Send formal invitations
Book horse/ghodi for baraat
Plan sangeet performances
Finalize menu with caterer
Shop for wedding jewelry
Book hotel room blocks for guests
Register for gifts (if applicable)

📅 1-3 Months Before

Final fittings for all outfits
Confirm all vendor bookings
Create detailed timeline for each event
Collect RSVPs and finalize headcount
Create seating charts
Bridal makeup trial
Finalize sangeet song list with DJ

📅 Final Week

Confirm final headcount with all vendors
Final walkthrough at venues
Prepare vendor payments
Pack for honeymoon
Assign family members to help with coordination
Relax and enjoy! 🎉
